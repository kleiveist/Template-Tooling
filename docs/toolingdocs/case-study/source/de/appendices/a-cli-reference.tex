\section{CLI-Referenz}
\label{app:cli-reference}

Die Fallstudie verwendet nur Befehle, die gegen die reale CLI dokumentiert sind:
\texttt{python tools/control.py integrate --check}, \texttt{python tools/control.py
integrate --full-fix}, \texttt{python tools/control.py tooling verify} und
\texttt{python tools/control.py tooling export}. Diese Beispiele gehören zur
\Verified{} Dokumentationsprüfung (\evidence{EV-CLI-001}).
